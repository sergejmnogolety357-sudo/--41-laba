1. Что такое Git и для чего он используется?

Git — это консольная утилита и система контроля версий, которая фиксирует историю изменений в файлах проекта. Она используется, чтобы в любой момент можно было откатиться к старой рабочей версии кода, а также для совместной работы нескольких программистов над общим проектом без риска перезаписать чужие изменения.



2. В чём разница между централизованными и распределёнными системами контроля версий?

В централизованных системах (например, SVN) вся история изменений хранится строго на одном выделенном сервере, и без интернета работать с ней нельзя. В распределённых системах (как Git) каждый разработчик скачивает себе на компьютер полную копию всей истории проекта, что позволяет делать коммиты и смотреть логи локально без сети.



3. Что такое репозиторий в Git?

Репозиторий — это директория (папка) вашего проекта, в которой Git отслеживает все изменения. Внутри неё создается скрытая папка .git, где хранятся база данных коммитов, настройки проекта, история изменений всех файлов и указатели на ветки.
