1. git init — инициализация нового локального репозитория в текущей папке.
2. git clone [url] — клонирование (копирование) удаленного репозитория на локальный компьютер.
3. git status — проверка текущего состояния рабочего дерева (какие файлы изменены или еще не отслеживаются).
4. git add [файл] — добавление измененных файлов в индекс (область подготовленных файлов) для следующего коммита.
5. git commit -m "сообщение" — фиксация сохраненных в индексе изменений и создание новой точки в истории проекта.
6. git push — отправка выполненных локальных коммитов в удаленный репозиторий на сервере (например, GitHub).
7. git pull — получение последних изменений из удаленного репозитория и их автоматическое слияние с локальной копией.
8. git log — просмотр истории всех сделанных коммитов с информацией об авторе, дате и описании.
9. git branch [имя_ветки] — создание новой изолированной ветки для разработки отдельного функционала.
10. git checkout [имя_ветки] — переключение между существующими ветками или возврат к конкретному коммиту из истории.
